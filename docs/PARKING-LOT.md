## Vibe Kanban (BloopAI) — orchestration board for parallel coding agents
- https://www.vibekanban.com/ · OSS: https://github.com/BloopAI/vibe-kanban (~28k stars)
- Status 2026-02: hosted product sunsetting; continues community-maintained OSS (`npx vibe-kanban`)
- The idea worth stealing: **the bottleneck moved from writing code to planning and reviewing it.** Kanban where every card runs a coding agent (Claude/Codex/OpenCode/Gemini…), auto-managed git worktrees per task, plan → prompt → review panels, diff review + comments, built-in browser to QA running dev servers, issue tracker wired to agent/PR lifecycle.
- Relevant to us: Wrangle's MCP server idea (B72) is the inverse direction (drive boards *from* an agent). A Wrangle-flavored take on agent orchestration would be "the Shutdown ritual for your agents" — review queue as the evening close.
