# Wrangle

*"What to do, what I'm thinking about, what I'm learning, what I'm spending."*

A PWA that holds four things in one place: **Tasks** (Trello-style kanban per project), **Ideas** (impact/effort scored), **Learning** (Want → Learning → Learned pipeline), and **Money** (expenses with receipts). Solo-first, shareable per-project via invite links. The flagship **Loop** — Dump your brain, close your day, wrap your month — lives on top (`docs/FLAGSHIP-2026.md`).

## Stack

Next.js 16 (App Router, Turbopack) · React 19 · TypeScript strict · Tailwind CSS v4 (CSS-variable tokens, dark default) · PostgreSQL on Neon + Drizzle ORM · Auth.js v5 (Google + GitHub OAuth, DB sessions) · zod · Server Actions · @dnd-kit · Vitest + Playwright + GitHub Actions CI.

## Run locally

```powershell
npm install
npm run dev          # http://localhost:3000  ("-- -p 3001" if taken)
```

Required env in `.env.local` (template: `.env.example`):

| Var | What |
|---|---|
| `DATABASE_URL` | Neon **pooled** connection string |
| `DIRECT_DATABASE_URL` | Neon direct string (migrations only) |
| `AUTH_SECRET` | `node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"` |
| `GOOGLE_CLIENT_ID/SECRET`, `GITHUB_CLIENT_ID/SECRET` | redirect URIs `{origin}/api/auth/callback/google` and `/github` for **every origin:port you run on** |
| `CLOUDINARY_*` | optional — receipts/card images |
| `SENTRY_DSN`, `NEXT_PUBLIC_SENTRY_DSN` | optional — error tracking stays dormant until set |

First login auto-creates **My Space** (personal project + 3 seeded boards + expense categories).

## Database

Schema lives in `db/schema.ts`. Change there, then:

```powershell
npm run db:generate                    # drizzle-kit generate → drizzle/00NN_*.sql
node --env-file=.env.local scripts/migrate.mjs   # apply (idempotent, tracked by filename)
npm run db:migrate                     # same, without env-file (reads shell env)
```

Two migration namespaces in `drizzle/`: **`0xxx` = generated by drizzle-kit** (rename to something semantic before committing), **`1xxx` = hand-written supplements** (raw SQL features Drizzle can't express). Both are applied by `scripts/migrate.mjs`; never reuse a prefix. **Do NOT use `drizzle-kit push`** — its websocket stalls in this environment.

## Scripts

```powershell
npm run typecheck      # tsc --noEmit
npm run lint           # eslint (next lint is removed in Next 16)
npm test               # vitest unit tests
npm run test:e2e       # playwright (boots its own server on :3100)
node --env-file=.env.local scripts/selftest.mjs   # authenticated smoke vs running server (SERVER_URL)
node --env-file=.env.local scripts/backfill-boards.mjs  # seed boards for projects missing them
```

## Deploy

Vercel + Neon: same env vars in Vercel (production → Neon `main` branch), production OAuth redirect URIs, `npm run db:migrate` as a deploy step (never auto-on-boot). Hobby tier covers personal, non-commercial use.
